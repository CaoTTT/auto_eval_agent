# 对比评估统计 Excel 子表

`compare` 的完整 XLSX 导出新增一个「对比评估统计」Sheet。新建任务、历史任务、同步下载和后台生成均经过同一导出器。原有逐题评分、图片、视觉证据和 CSV/JSON 的评分结构保留。

## 使用与配置

更新代码并重启 Web 服务后，对任务重新点击「导出 XLSX（完整）」即可。已下载或仍在有效期内的旧导出文件不会自动更新。数据来源是导出开始时冻结的任务快照，不读取原 Excel，也不调用模型。

适用标准为 `qa_competitor_compare@0.2-simplified` 和 `qa_competitor_compare@0.3`。当前和旧 bundle `0.2.0/0.2.1/0.3.0/0.3.1` 按协议恢复。标准或实现版本未知时展示运行诊断和原因，不猜测评分范围。异常混合版本、混合产品数量的快照分组展示，不跨组混算。

默认显示「产品1/2/3」，不从文件名猜测身份。API 任务可在 `options.product_names` 传与产品位置一致的名称列表，例如 `["小艺基线组", "小艺实验组", "豆包"]`，只影响统计显示。重用数据后若调整产品位置，应同步调整名称。

## 子表内容

| 区域 | 输出 |
| --- | --- |
| 说明 | 任务、数据集、统计版本、UTC 导出时间、缺失值和计算口径 |
| A | 成功覆盖率、技术失败、未完成、置信度、复核、失败原因、输入状态、两类 Gate、内容冲突 |
| B | 维度适用性、核验状态、评分覆盖、应评分完整率、产品均分/中位数、达标/低质/满档/最低档率、分档和缺分原因 |
| C | 两两均分、双向分位值、配对分差、达标率差、低质率差、双向 GSB 数量和比例、净胜率、置信区间、分差分布、门槛对比 |
| D | 三产品共同样本的覆盖率、独占第一、两方并列第一、三方同分、独占末位，并补充共同样本的全部六向比较 |
| E | 按文字/图文、录屏/长截图、场景分类输出双向分位值、分差与 GSB 核心指标 |
| F | 人工评分、人工适用性/Gate、重复实验、位置互换的验证指标和数据缺失说明 |

准确性只输出适用性与核验诊断，不计算其均分、GSB、分位值或排名。两个标准没有正式维度权重，均不生成加权总分、综合胜方或总体排名。

## 固定计算口径

- 每题仅取最新结果，按输入索引对齐，重跑不重复计数。未完成、技术失败和产品质量低分分别计数。
- 不以内容冲突 unclear 或单个产品输入 failed 整题删除数据。不适用、无法核验、输入失败、Gate 阻断和评分缺失不补 0 或最高分。
- 输入 partial、Gate unclear、部分核验或风险切片，若所选协议仍允许有效评分，则保留该分数，并标记「受限证据题数」。置信度和复核需求只作诊断，不是裁判准确率。
- Gate 分母仅包含该产品已产生结构化结果且输入 complete/partial 的题目。输入 failed 导致的强制 unclear 单独统计。缺失状态不会自动按通过处理。
- 内容冲突率 = yes / (yes + no)，unclear 与状态缺失单列。三产品整体冲突不归责到某产品或某一对产品。
- 维度适用率 = 适用题数 / 有布尔适用性判断的题数。核验状态分布的分母为适用题数。
- 评分覆盖率 = 有效评分数 / 适用题数。应评分输出完整率 = 有效评分数 / 按协议应评分数；不适用、无法核验和 Gate 阻断不会被误算为输出缺失。
- 当前 V0.2 必须响应 Gate=pass 才保留分数，安全 Gate 按该版实际规则独立统计；V0.3 任一 Gate=fail 阻断，unclear 允许继续评分。导出不修改协议或已有分数。
- 只有范围内的整数型数值参与统计；0 是 V0.3 的合法分数。字符串、布尔值、非整数、越界、NaN 和无穷大单独计为格式/范围异常。

### 两两对比

令 A、B 同一维度都有有效分的题目集合为 S，N=|S|：

- 均分来自同一个 S；分位值 = mean(A) / mean(B)，以 Excel 百分比显示。例如 4/5=80%，5/4=125%。分位值不是 P50/P90 统计分位数，也不是逐题比值的平均。
- 对照均分为 0 时显示「—」，并注明不可计算原因；分子为 0 且分母非零时正常输出 0%。
- G = A>B 题数，S = A=B 题数，B = A<B 题数。胜/平/负率分别除以 N，净胜率=(G-B)/N。
- 均分差为 mean(A-B)，达标率差和低质率差也在 S 上计算。所有反向统计用同一集合重定向。
- 双产品输出 1/2、2/1；三产品输出 1/2、2/1、1/3、3/1、2/3、3/2。每个维度都有全部方向，包括无有效样本时的空指标和 0 题数。
- 产品3失败时，1/2仍可使用有效配对。三方排名只用三个产品均有分的交集；另输出该交集上的六向对比，便于横向分析竞争关系。
- 分位值与 GSB 使用同一配对集合。各产品独立均分表使用各自有效样本，不能将不同样本的独立均分直接作为配对分差。

### 阈值与置信区间

统计阈值集中在 `web/compare_statistics.py` 的 `THRESHOLDS`：V0.2 达标≥4、低质≤2；V0.3 达标≥2、低质≤1。它们是版本内的运营统计定义，不修改评分标准，不代表跨版本等价。完整分档分布同时保留。

全量两两与三方共同样本的分差、净胜率提供 95% 配对题组百分位 Bootstrap 区间。优先按 session_group 分组，否则相同 Query 与提问图身份一起分组；固定 seed=20260911，重采样2000次。实现压缩相同题组贡献后使用 multinomial 重采样，限制中间矩阵内存。少于两个独立组不估计，退化区间明确标注。场景等细分子集仅输出点估计，避免重复大量区间计算。

区间仅反映本样本的抽样不确定性，不包含裁判系统误差；不自动推导显著性冠军。全量按题计算，场景均值不直接平均；没有现网采样权重时结论仅限本测评集。

F 区不从一轮模型结果推断人机准确率或稳定性。当前快照没有正式人工标注/重复实验输入协议，因此显示「未开展」及所需数据。失败补跑不视为独立重复实验。

## 工程边界

新统计仅在 XLSX 生成时计算，后台导出仍在线程中处理，使用现有容量和内存限制。百分比、分数、题数为数值单元格；缺失结果为「—」并附相应口径或原因。统计冻结于导出时，编辑逐题表不会联动重算，需要重新导出。

原有「汇总指标」的完成/失败/未完成计数在导出时重新对齐快照；页面 compare summary 也将未完成与技术失败分开。旧汇总其余兼容字段继续保留；新子表的每个产品对显式给出其有效样本数。
