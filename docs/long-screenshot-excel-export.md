# 长截图 Excel 原图导出

长截图任务导出 XLSX 时，新增「原始长截图」工作表。每条 Query 占一行，按输入顺序排列；产品 1、2、3 各占一个原图列。双产品任务不增加产品 3 列，混合双/三产品批次在没有第三个产品的行留空。失败或尚未评估的条目也保留原行。

## 图片内容

- 嵌入采集的完整原始文件，不拼接、不切图、不缩放像素、不转色、不重新编码；即使评测请求使用了切片，也只导出完整原图。
- 工作表里的图片随单元格缩小显示；完整分辨率及原始文件字节保存在 XLSX 内。行高只影响显示大小。
- 使用快照的 `screenshot_metaN.original_path`，回退到 `screenshotN` 或历史 `source_data.screenshotN`；相对路径按项目根目录解析。
- 快照包含原图 SHA-256 时，导出前检查文件是否被替换。缺失、损坏或已变更的图片在对应单元格标明原因，不以模型切片或其他产品图片代替。
- 相同文件字节在 XLSX 中只保存一次，各单元格分别引用；不会因文件同名、题号或 Query 相同而错误合并图片。

## 查看方式与兼容性

原图页采用 WPS 的单元格内嵌图片结构（`DISPIMG` 和 `xl/cellimages.xml`），不需要联网、宏或外部图片目录。使用支持此功能的 WPS 桌面版打开，在原图单元格双击或使用图片预览查看完整图片。实际双击入口、极长图片、WebP 和 CMYK JPEG 的显示需要在使用的 WPS 版本中验收。

Microsoft Excel 不保证识别 WPS 的 `DISPIMG`，可能在原图页显示公式或不支持提示；其余数据和评分工作表保持原有格式。原文件仍在 XLSX 的 `xl/media/` 内，可以按原字节提取。导出后不要对图片执行 WPS/Excel 的图片压缩操作，否则再次保存时可能改变图片质量。

## 部署与测试

更新 `src/auto_eval/web/history.py` 和新增的 `src/auto_eval/web/xlsx_images.py` 后重启服务。沿用现有 XLSX 导出接口，不增加配置、上传页面或安装依赖。旧录屏任务的导出不增加图片页，CSV/JSON、评分列和评测请求保持不变。

自动化测试位于 `tests/test_long_screenshot_xlsx.py`，覆盖原字节一致、完整长图、格式、双/三产品映射、历史快照、异常原图、ZIP/XML 引用完整性和现有导出接口。自动化结构检查不能替代 WPS 双击预览实机验收。

完整原图会增加 XLSX 体积；当前导出接口仍在内存中生成 XLSX，图片逐张写入且相同内容去重，但大批量任务仍需预留导出内存。
