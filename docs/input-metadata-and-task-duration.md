# 测试数据扩展字段与任务总耗时

## 输入与 Excel 导出

上传支持 JSON 数组、单个 JSON 对象、每行一条对象的 JSONL，以及已有的 CSV 格式。例如：

```json
[
  {
    "id": "case-001",
    "query": "介绍一下这款产品",
    "video1": "data/product-a.mp4",
    "video2": "data/product-b.mp4",
    "sessionid": "0001234567890123456789",
    "业务分类": "商品问答",
    "标签": ["图文", "多轮"]
  }
]
```

原始输入中的额外字段保存在任务快照中，导出 Excel 时自动追加到“数据集明细”和“逐题结果”。CSV 和单条结果导出也使用同一映射。

- 字段按输入中的首次出现顺序合并成列，不同数据缺少的字段留空。
- 对象和数组以 JSON 文本保存；明确的 `null` 保存为文本 `null`，与字段缺失区分。
- 遇到已有导出列名时，额外字段使用 `输入字段.<原名>`，必要时追加编号，避免覆盖结果。
- 长整数以文本保存；带前导零的标识符请在 JSON 中使用字符串。
- 扩展字段不会加入模型提示词，也不改变会话分组；`sessionid` 可用于导出后关联业务数据。
- 已有历史任务中保存的原始字段同样可导出。

## 任务总耗时

执行页面和历史列表新增“任务总耗时”。从任务实际获得执行机会开始，到本次评测完成或异常终止为止，使用单调时钟统计真实经过的时间，包含证据准备、媒体处理、模型额度等待、模型调用和本次执行中的重试。并行 case 的耗时不会相加，任务在执行队列中等待的时间不计入。

运行中持续更新；结束后固定保存。刷新页面、服务重启后加载完成任务、修改历史备注，都不会延长已完成的耗时。用户发起的失败补跑沿用独立的补跑记录，不修改原任务耗时。

旧任务没有准确计时数据时显示“未记录”。服务在执行中意外中断时，仅能保留最后一次落盘的已测时间，显示“截至中断前”，不将服务停机时间计算进去。

## 验证范围

回归覆盖 JSON / JSONL / CSV 输入、字段碰撞、失败与未完成结果、长标识符、对象与数组、旧记录兼容、Excel 图片与产品列，以及排队、运行、结束、异常、中断、补跑、历史加载和 SSE 重连计时。界面截图使用本地模拟任务，不调用真实模型。
