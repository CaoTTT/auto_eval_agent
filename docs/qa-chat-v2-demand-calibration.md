# 闲聊V2需求与分档校准候选

平台新增 **问答闲聊V2·需求与分档校准·1-5分（候选）**，用于减少把分享当求方案、把简单完整回答当单薄，以及理由与分档脱节的问题。原“问答闲聊V2·1-5分（候选）”和默认标准保持原样。

## 本次调整

仅调整理解需求、情感表达恰当、风格恰当、场景化满足、引导推荐五维的执行说明：

1. 先判断当前主要目的、明确要求和有依据的隐含需求，再选择相关评价子项。分享、倾诉不必额外提供方案；求方法或话术不机械要求先安慰。必要澄清不直接视为回应不足。回答实际引入的缺陷仍须评价。
2. 五维逐产品核对证据、实际表现及影响与原档位。3/4分说明具体不足及影响，5分说明相关高分要求如何满足。不因简短或常见表达自动降分，不因没有指出缺点自动满分，不增加默认分、固定扣分或分数上限。

原标准全文与案例直接复用原模块，原输入USER模板、输出示例和Schema也复用原实现。个性化适配、Gate、维度适用性、核验及空分规则不调整。
