# 闲聊V2需求与分档校准候选

平台提供 **问答闲聊V2·需求与分档校准·1-5分（候选）**，用于减少把分享当求方案、把简单完整回答当单薄，以及理由与分档脱节的问题。新任务使用扣分制修订 **1.1.3**；原“问答闲聊V2·1-5分（候选）”和默认标准保持原样。

## 本次调整

本次调整六维的评分执行方式，保留测评标准原文、1/3/5分锚点及案例：

1. **先检查是否可评分，再从5分起评。** Gate、适用性、核验与空分状态优先。材料足够且逐项核对后没有有效缺陷时保留5分；不适用、无法核验或被Gate阻断时沿用原规则返回null。
2. **只为有效缺陷扣分。** 每项扣分必须有可定位证据、当前需求或原标准依据、该维实际不足及影响。原表中的表面适配、机械共情、低价值引导、冗余等仍属于检查范围。不是只检查严重错误，也不以缺少可选亮点扣分。
3. **按综合影响扣分。** 本维综合扣0/1/2/3/4分分别得到5/4/3/2/1分，对齐原表相应锚点及2/4分表头。不按问题个数机械扣1分，不在同一维度重复扣同一缺陷，不凭其他亮点抵扣已成立的缺陷。
4. **各维独立、产品同尺度。** 理解、场景、情感、风格、引导和个性化分别说明影响，不能把“通用、略浅、像模板”复制为多维扣分。所有活动产品都使用5分起点和同一扣分尺度，先独立绝对评分，再比较。
5. **按本轮需要检查必要回应。** 分享与陪伴不强制方案，明确求方法时也不能仅给安慰。开放追问和二选一不按形式加减分；个性化先核对该产品可知的信息及其本轮相关性；无引导需求且未引导仍是不适用。

原标准全文与案例、输入USER、输出示例和Schema仍直接复用原实现。个性化适配的原有缺陷、Gate、维度适用性、核验及空分规则保留。本次不将复核中的所有人工高分自动视为金标；关键指代未澄清、无依据补全经历等问题仍须评价。

## 历史证据核对补强（修订1.1.2）

基于新一批216题的审核，候选已覆盖需求识别和相关子项分档，本次优先补强评分前的证据核对，不再增加单题案例或新的评分条件：

1. 声称“未回应、缺少、未提供”前，完整核对目标轮图文及语义等价内容；区分确实缺失、已有但不足和材料无法确认。复制文本冲突继续按原视觉证据优先级处理。
2. 保留主语、否定、条件、确定程度及先后顺序，区分祝愿、希望、可能性与事实断言；条件词也不是免责条件。检查整段正负证据，不由一句正确提醒抹去其他矛盾。
3. 分开采集时刻、评测运行时刻和用户明确的事件时间。时间位置不能独立推出生日、经历或活动；产品自述不独立证明历史真实，来源不清也不单独证明编造，仅限制依赖该来源的维度。
4. 按各产品自身证据先绝对评分，再比较结果。另一产品多给的分析、选项或新颖措辞，不自动成为本产品的缺陷；跨维评价需要独立影响。

平台仍使用同一候选标签、协议ID、标准版本和结果Schema，输入USER模板及双/三产品56/78键保持不变。原标准全文、Gate、适用性、核验、空分与个性化规则未改。

该次发布的新任务使用1.1.2，1.1.1历史任务继续绑定原模板；当前新任务已升级至1.1.3。标准边界和证据不足的案例仍需统一口径或补证，不替其发明确定答案。
