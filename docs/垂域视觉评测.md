# 垂域视觉评测

`mode=rich_content` 用于检查问答产品录屏中 assistant 回答区域的结构化挂卡和蓝色
Superlink 文字。该模式复用任务类（录屏）的视频路径校验、延迟抽帧、Web 会话目录、进度、
历史和 `judge_calls`，但使用独立抽帧参数、视觉提示词和结果结构。

## 1. 评估口径

- 普通内嵌图片、正文截图和纯文本段落不算挂卡。
- assistant 当前回答区域中的蓝色文字按可点击 Superlink 统计。
- 同一挂卡或链接跨帧重复出现只计一次；同样文字位于回答的两个不同位置时计两次。
- 没有挂卡或 Superlink 只表示观察结果，不自动视为回答错误。
- 仅对实际出现的挂卡评价垂域、实体、时间地点等条件及正文一致性。
- 模式不输出问答类 `correctness`，Web 汇总使用挂卡出现率、挂卡合适率、Superlink
  出现率和待人工复核数。

## 2. JSONL 输入

```json
{"id":"rich_001","query":"北京明天天气怎么样","context":"当前地点北京","video_path":"data/rich_content/weather.mp4","category":"weather","answer_text":"北京明天晴","task_start_time":0,"task_end_time":18.5}
```

| 字段 | 必填 | 说明 |
|---|---:|---|
| `query` | 是 | 用户问题 |
| `video_path` | 是 | 本地视频路径，相对路径以项目根目录为基准 |
| `id` | 否 | 稳定题号 |
| `context` | 否 | 时间、地点等可信背景 |
| `category` | 否 | 实际业务垂域；为空时显示为通用，不额外调用分类模型 |
| `answer_text` | 否 | 只辅助理解语义，不能证明视觉对象存在 |
| `task_start_time` | 否 | 任务开始时间，单位秒，默认 0（兼容旧字段 `content_start_time`） |
| `task_end_time` | 否 | 任务结束时间，单位秒（兼容旧字段 `content_end_time`） |

批量导入只解析和展示数据；点击"开始评估"后才校验视频、抽帧和调用视觉裁判。

## 3. 主要输出

```json
{
  "answer_coverage": "complete",
  "turn_summary": "用户问北京明天天气，助手给出晴26～34℃的天气卡和一个链接",
  "card_presence": "present",
  "card_count": 1,
  "card_types": ["weather"],
  "card_contents": ["晴，26～34℃"],
  "card_suitability": "ok",
  "superlink_presence": "present",
  "superlink_count": 2,
  "superlink_texts": ["逐小时预报", "未来15天天气"],
  "superlink_suitability": "ok",
  "problem_solved": "ok",
  "answer_issues": "",
  "needs_review": false
}
```

逐对象证据（核心实体、回答位置、证据帧、置信度）随裁判明细日志 `judge_calls` 留档。
回答未完整覆盖（`partial`）时，已观察到的链接数量只是下界；`unclear` 且未观察到链接时
数量为 `null`。多轮会话中每轮另产出 ≤120 字 `turn_summary`，注入下一轮评测的 context。

## 4. 配置与代码

- `config/visual_modes/rich_content.yaml`：挂卡类型、垂域显示名映射（category_display）和抽帧参数。
- `src/auto_eval/judges/rich_content_judge.py`：强类型解析与稳定结果字段。
- `src/auto_eval/judges/prompts.py`：视觉识别与跨帧去重规则。
- `src/auto_eval/web/video_prepare.py`：复用视频路径、缓存和会话抽帧基础设施。

当前抽帧版本为 `rich-content-v1.1.0`，默认以 1.5 FPS 生成候选，最多保留 20 帧；
视觉输入使用最长边 1280、JPEG 质量 85，以保留小号蓝色文字。
